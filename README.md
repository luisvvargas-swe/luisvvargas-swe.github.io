# Luis Vargas · Software y automatización

[Visitar el sitio](https://luisvvargas-swe.github.io/)

Página de servicios en español, de una sola columna, con presentación, servicios, experiencia resumida y contacto. Fondo blanco, tipografía Inter, texto negro y gris y efectos de vidrio discretos en controles. No incluye un catálogo visible de demos o proyectos en desarrollo.

## Estructura

- `index.html`: contenido y navegación por anclas.
- `assets/minimal.css`: diseño adaptable, estados de interacción y preferencias de movimiento y transparencia reducidos.
- `assets/minimal.js`: reflejo en controles según la posición del cursor. El contenido y los enlaces funcionan sin JavaScript.
- `assets/monogram.svg`: icono del sitio.

La fuente Inter se carga desde Google Fonts, con alternativas del sistema. GitHub Pages publica desde la raíz de `main`; no requiere compilación, claves ni servicios de pago.
