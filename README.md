# Luis Vargas · Portafolio profesional

[Visitar el portafolio](https://luisvvargas-swe.github.io/) · [Descargar CV](./luis-vargas-cv.pdf)

Portafolio de Luis Armando Vargas Peña. Incluye cuatro demos que se ejecutan en el navegador, sin instalar herramientas ni configurar claves.

- [Cotizador de refacciones](https://luisvvargas-swe.github.io/proyectos/cotizador/): revisa una solicitud contra un catálogo ficticio, corrige partidas y exporta el resultado en CSV.
- [Scouting geométrico](https://luisvvargas-swe.github.io/proyectos/scouting/): compara perfiles ficticios con dos distancias estadísticas. Adaptación del [cuaderno académico](https://github.com/Luisvvargas/data-mining/blob/main/Unit%20-%20III/scouting%20geometrico.ipynb).
- [Meraki B2B](https://luisvvargas-swe.github.io/proyectos/mayoreo/): prueba los niveles de volumen y genera una solicitud mayorista de ejemplo. Adaptación del [proyecto universitario](https://github.com/Luisvvargas/meraki-b2b).
- [Inspección visual](https://luisvvargas-swe.github.io/proyectos/inspeccion/): examina un blíster sintético con análisis de píxeles. Recreación didáctica inspirada en mi experiencia en visión artificial.

Para probar el sitio localmente, descarga el repositorio y abre `index.html` en un navegador. GitHub Pages publica desde la raíz de `main`.
