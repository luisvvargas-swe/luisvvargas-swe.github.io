# Luis Vargas · Portafolio profesional

[Visitar el portafolio](https://luisvvargas-swe.github.io/) · [Descargar CV](./luis-vargas-cv.pdf)

Portafolio de Luis Armando Vargas Peña. Incluye cuatro demos que se ejecutan en el navegador, sin instalar herramientas ni configurar claves.

- [Cotizador de refacciones](https://luisvvargas-swe.github.io/cotizador-de-refacciones/) · [Código](https://github.com/luisvvargas-swe/cotizador-de-refacciones). Revisa una solicitud contra un catálogo ficticio, corrige partidas y exporta el resultado en CSV.
- [Scouting geométrico](https://luisvvargas-swe.github.io/scouting-geometrico/) · [Código](https://github.com/luisvvargas-swe/scouting-geometrico). Compara perfiles ficticios con dos distancias estadísticas. Adaptación del [cuaderno académico](https://github.com/luisvvargas-swe/scouting-geometrico/blob/main/notebooks/scouting-geometrico.ipynb).
- **Meraki B2B.** Portal universitario de venta mayorista en tres idiomas con carrito, solicitudes de muestra y seguimiento simulado de pedidos. La demo permite configurar cantidades y generar una solicitud mayorista de ejemplo. [Probar configurador](https://luisvvargas-swe.github.io/meraki-mayoreo-demo/) · [Código de la demo](https://github.com/luisvvargas-swe/meraki-mayoreo-demo) · [Proyecto original](https://github.com/luisvvargas-swe/meraki-b2b).
- [Inspección visual](https://luisvvargas-swe.github.io/inspeccion-de-blisteres/) · [Código](https://github.com/luisvvargas-swe/inspeccion-de-blisteres). Examina un blíster sintético con análisis de píxeles. Recreación didáctica inspirada en mi experiencia en visión artificial.

Para probar el sitio localmente, descarga el repositorio y abre `index.html` en un navegador. GitHub Pages publica desde la raíz de `main`.

Contacto: luisvargas.swe@gmail.com
